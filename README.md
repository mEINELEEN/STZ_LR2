# Лабораторная работа №2 — Захват изображений с веб-камеры

## Описание проекта

Программа на Python для подключения и настройки встроенной веб-камеры, захвата видеокадров и исследования характеристик видеопотока с использованием OpenCV.

## Возможности

- Подключение к веб-камере и получение изображений.
- Настройка параметров захвата видео.
- Сравнение четырёх разрешений: 320×240, 640×480, 1280×720 и 1920×1080.
- Измерение FPS и времени захвата кадров.
- Сохранение результатов экспериментов в CSV-файл.
- Обнаружение движения на изображении с помощью OpenCV.

## Технологии

- **Python**
- **OpenCV (`cv2`)**
- **CSV** для сохранения результатов измерений.

## Установка и запуск

Установите необходимые зависимости:

```bash
pip install opencv-python
```

Запустите основной файл программы:

```bash
python main.py
```

Выберите нужный эксперимент в главном меню.

## Цель работы

Изучить подключение и настройку видеокамеры, исследовать зависимость характеристик захвата видео от разрешения изображения и освоить базовые методы обработки видеокадров.
